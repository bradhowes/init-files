# init-files

My collection of init files for shells, Python, Emacs, etc.

# Emacs Compilation

If desired, you can recompile all of the Emacs files in [user-lisp](emacs.d/user-lisp) via `M-x compile`. It properly
moves into the `user-lisp` directory and runs Emacs in batch mode to recompile everything in the directory.
